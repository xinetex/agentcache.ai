Agent Capability Firewall

The LLM is a non-deterministic planner. It proposes actions; it never executes them. Every proposal passes a deterministic policy enforcement point before it reaches an API, shell, database, payment rail, or comms channel — authority the model cannot talk its way past.

Booking is allowed; modifying another person's booking is not. 17 tests pass across the firewall and breaker.

Swarm defense

5 / 8

8 independent agents each made one low-risk call to the same new domain. The collective circuit breaker tripped at 5 converging agents and quarantined the cluster — governing the aggregate, not each action in isolation.

Backed by lib/firewall.js + lib/swarm-breaker.js (17 tests) and examples/gym-incident-demo.mjs. Design: AGENT_FIREWALL.md. The long-term target is an agent-native authorization standard — who delegated what authority, for what purpose, over what time, with what limits and revocation path.
