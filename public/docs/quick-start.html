Walk through governed execution

For a buyer or design partner, follow the read-only JettyThunder pilot path. Shadow drift scoring below is optional telemetry; it does not authorize or execute a provider action.

1. Get Your API Key

Create an account at agentcache.ai/signup, finish onboarding, then open your workspace dashboard to generate an API key.

2. Install SDK

npm install agentcache-client

3. Initialize Client

import { AgentCache } from 'agentcache-client';

const cache = new AgentCache({
  apiKey: 'ac_live_your_key',
  baseUrl: 'https://agentcache.ai',
  namespace: 'default'
});

Optional: Test The API Directly

curl -X POST https://agentcache.ai/api/cache/set \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "X-Cache-Namespace: default" \
  -d '{
    "provider": "openai",
    "model": "gpt-4o-mini",
    "messages": [{"role":"user","content":"What is 2+2?"}],
    "response": "4"
  }'

4. Cache AI Responses

const cached = await cache.get({
  provider: 'openai',
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'What is 2+2?' }]
});

if (cached.hit) {
  console.log('Cache hit!', cached.value);
} else {
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'What is 2+2?' }]
  });

  await cache.set(
    {
      provider: 'openai',
      model: 'gpt-4o-mini',
      messages: [{ role: 'user', content: 'What is 2+2?' }]
    },
    response.choices[0].message.content
  );
}

AgentCache Core is designed to sit above provider choice. The same cache contract works with hosted providers like OpenAI, Anthropic, and Gemini, and with open-local runtimes through Ollama. If you are serving a Gemma-family model locally, use provider: 'ollama' and the model tag you installed on your Ollama node.

5. Cache Tool Calls

const toolInput = JSON.stringify({ city: 'San Francisco' });

const weatherCache = await cache.get({
  provider: 'tool',
  model: 'get_weather',
  messages: [{ role: 'user', content: toolInput }]
});

if (!weatherCache.hit) {
  const weather = await fetchWeather('San Francisco');
  await cache.set(
    {
      provider: 'tool',
      model: 'get_weather',
      messages: [{ role: 'user', content: toolInput }]
    },
    weather,
    { ttl: 1800 }
  );
}

6. Monitor Your Savings

const stats = await cache.stats();

console.log(`Cache hit rate: ${stats.metrics.hit_rate}%`);
console.log(`Money saved: ${stats.metrics.cost_saved}`);
console.log(`Requests cached: ${stats.metrics.total_requests}`);

7. Optional: Evaluate workflow drift

This shadow evaluation compares a run with its expected path and records recommendations. It is a separate observation feature: it does not block provider calls or replace the policy, scope, and approval checks in governed execution.

curl -X POST https://agentcache.ai/api/execution/runs/YOUR_RUN_ID/evaluate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "mode": "shadow"
  }'

8. Governed Execution Pilot

The first design-partner slice governs a read-only JettyThunder storage summary. Follow the guided execution workflow; it describes the product path without pretending a live provider account has been connected.

  1. Connect an individual or organization AgentCache API key.
  2. Save a user-owned JettyThunder service key with a read scope.
  3. Create a context pack that allows only the aggregate storage-summary action.
  4. Start a run, approve its gate as a different organization owner or administrator, then execute the read.
  5. Inspect the policy decision, approval, provider outcome, and redacted invocation history.

9. Pilot Readiness Checklist

  • A provider-confirmed approved read completes in the isolated Preview environment.
  • A prohibited action is denied before provider traffic and appears in history.
  • Expired credentials and provider errors remain distinguishable from policy denial.
  • Buyer-facing measures are defined before the pilot: repeat use, investigation time, prevented unsafe calls, and direct delivery cost.
