# x402 payment status

AgentCache does not currently accept x402 payments. Do not send funds to a wallet address or treat a `Preauthorization` header as proof of payment.

The experimental settlement code is disabled at the API authentication boundary because it does not verify a facilitator-issued payment payload or an on-chain transaction before granting access. AgentCache does not publish a production treasury address or x402 price.

## Supported billing paths

- Use an authenticated AgentCache API key for API requests. Account quotas and eligible credits are applied by the billing service.
- Use AgentCache-hosted Stripe Checkout for supported subscriptions, add-ons, and the fixed-scope Agent Run Risk & Savings Audit.
- Governed execution usage is measurement-only during the pilot. Governed actions are not charged automatically.

## What must be verified before x402 can be enabled

1. A real facilitator or payment verifier validates signed payment payloads and network/asset/recipient/amount.
2. Replays, refunds, expiry, and settlement reconciliation are handled idempotently.
3. A controlled treasury address and accounting owner are configured and independently checked.
4. Integration tests exercise invalid, expired, replayed, underpaid, overpaid, and valid payments against the payment provider's test environment.

Until those gates pass, any x402 references in older SDKs or design material are historical or experimental and must not be used to authorize API access.
